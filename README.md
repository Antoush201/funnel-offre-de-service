# OLA Funnel — Déploiement Vercel

## Setup local

```bash
npm install
npm run dev
```

## Déployer sur Vercel

1. Va sur [vercel.com](https://vercel.com) et connecte ton GitHub
2. Crée un nouveau repo GitHub et push ce projet
3. Dans Vercel → "Add New Project" → sélectionne le repo
4. Framework : **Vite**
5. Clique **Deploy**

## Ou via CLI

```bash
npm install -g vercel
vercel
```

Vercel va détecter Vite automatiquement.
